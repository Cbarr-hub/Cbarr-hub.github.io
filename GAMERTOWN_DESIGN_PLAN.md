# Gamertown — Frontend Design Reference

## Color Scheme

| Token | Hex | Usage |
|---|---|---|
| Primary Green | `#42F527` | CTAs, interactive elements, hover states |
| Black | `#000000` | Text, borders, backgrounds |
| Cream | `#EDF0C5` | Light backgrounds, text contrast |

## Layout

- **Header**: fixed, black bg, cream text — logo left, search center, nav right
- **Hero**: two-column grid (image + text), cream bg
- **Ad sidebars**: desktop only (~250px each), hidden on tablet/mobile
- **Content column**: 900px max-width, black text on cream
- **Footer**: black bg, cream text, contact form

## Responsive Breakpoints

| Breakpoint | Width | Notes |
|---|---|---|
| Desktop | 1200px+ | includes ad sidebars |
| Tablet | 768–1199px | single column, no sidebars |
| Mobile | < 768px | stacked, full-width |

## Design Principles

1. High contrast — black on cream
2. Green (`#42F527`) for all interactive elements
3. Whitespace-focused, minimal
4. WCAG-compliant color ratios, semantic HTML
